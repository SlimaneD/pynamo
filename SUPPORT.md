# Getting help

- **Learn pyNamo-EGT**: start with the [tutorial notebook](tutorial.ipynb) (also on [Binder](https://mybinder.org/v2/gh/pynamo-egt/pynamo/master?filepath=tutorial.ipynb) and [Colab](https://colab.research.google.com/github/pynamo-egt/pynamo/blob/master/tutorial_colab.ipynb)) and the [README](README.md). Every public function has a docstring: try `help(pn.phase_portrait)`.
- **Ask a question**: search the [existing issues](https://github.com/pynamo-egt/pynamo/issues?q=is%3Aissue) first; if your question isn't answered, open a new issue and describe what you're trying to do, with a short code example.
- **Report a bug**: use the [bug report template](https://github.com/pynamo-egt/pynamo/issues/new?template=bug_report.yml).
- **Suggest a feature**: use the [feature request template](https://github.com/pynamo-egt/pynamo/issues/new?template=feature_request.yml).

pyNamo-EGT is maintained by researchers in their spare time, so replies may take a few days.
